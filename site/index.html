Before installation

When a supported release exists, verify four things.

  1. Download the signed RustyFleet-Setup.exe only from GitHub Releases . Releases are the binary source of truth; this site hosts documentation and, when a supported release exists, short-lived signed metadata.
  2. Use only a signed release. Unsigned developer bundles identify themselves as development_only and cannot be published.
  3. Confirm the Setup Authenticode signer and the hash in the signed release descriptor before execution.
  4. Expand the archive and run the included offline validator before reviewing the installer plan.

What the Hostess provider means

Windows hotspot behavior remains owned by Rusty Hostess. Fleet records the provider’s public provenance and exact digest, then projects its structured result. It does not absorb hotspot credentials or invent a second implementation.
