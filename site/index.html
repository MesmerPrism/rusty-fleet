One reviewed bundle

The Windows archive carries a complete manifest, SHA-256 checksums, and an offline validation receipt for its exact contents.

Private inputs stay private

Credentials, pairing material, device serials, private configuration, and ADB are not distribution payloads.

Safe preview first

The installer shows its plan without changing the computer. Install or rollback happens only after an explicit execute choice.

Before installation

Verify the release in three checks.

  1. Download only from GitHub Releases . Releases are the binary source of truth; this site hosts no installers.
  2. Compare the ZIP with its adjacent .zip.sha256 file.
  3. Expand the archive and run the included offline validator before reviewing the installer plan.

What the Hostess provider means

Windows hotspot behavior remains owned by Rusty Hostess. Fleet records the provider’s public provenance and exact digest, then projects its structured result. It does not absorb hotspot credentials or invent a second implementation.
